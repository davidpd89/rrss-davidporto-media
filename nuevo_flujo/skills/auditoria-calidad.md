# SKILL: AUDITORIA DE CALIDAD

Usar antes de entregar a David, antes de programar y antes de cerrar lote.

---

## P0 - BLOQUEANTES

La pieza NO esta lista si:

- el gancho inicial no funciona solo;
- hay faltas de ortografia;
- el texto visual se corta o no se lee en movil;
- el caption repite literalmente el texto visual;
- el visual es stock generico sin transformacion ni razon;
- se repite fondo/tema/estructura de una pieza cercana;
- se inventa dato;
- no hay fuente/licencia para asset externo;
- ratio/formato no cumple la red;
- falta revision visual de David cuando aplica;
- Metricool se va a usar sin verificar campos obligatorios.

---

## P1 - CORREGIR EN LA MISMA SESION

- CTA generico.
- Hashtags demasiado amplios.
- Demasiadas negaciones seguidas.
- Metafora abstracta como primera linea.
- Exceso de marca/libro en una pieza interest-first.
- Caption largo donde la red pide corto.

---

## TEST ADVERSARIAL

Responder como juez hostil:

1. Esto podria publicarlo cualquier cuenta literaria anonima?
2. Si quito el nombre de David, queda algo propio?
3. La primera linea pararia a alguien sin sonido?
4. Hay una razon para guardar/comentar/compartir?
5. Estoy repitiendo una victoria vieja por comodidad?
6. David se enfadaria por algo ya documentado como fallo?

Si alguna respuesta incomoda aparece, corregir antes de entregar.
