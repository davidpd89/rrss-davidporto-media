# SKILL: PREGUNTAS PARA GPT / IA EXTERNA

Usar cuando haga falta pedir a GPT informacion, referencias o analisis que el agente incorporara despues al flujo.

---

## PRINCIPIO

GPT no debe devolver "ideas sueltas". Debe devolver datos estructurados que alimenten:

- `kb/patrones-ganadores-y-fallos.md`
- `06_Seguimiento/seguimiento_activo.md`
- `12_Metodo_y_recursos_IA/01_laboratorio_humano/`
- una pieza concreta en `03_Publicaciones/` o `09_Usados_video/`

---

## PAQUETES UTILES PARA PEDIR

### 1. Mejores publicaciones propias

Pedir a GPT una tabla con:

- red;
- URL o ID;
- fecha;
- formato;
- texto visual;
- caption;
- metricas disponibles;
- por que cree que funciono;
- que patron se puede repetir sin copiar.

### 2. Peores publicaciones propias

Misma tabla, pero enfocada en:

- que fallo;
- que patron IA aparece;
- como corregirlo;
- si se debe reciclar o descartar.

### 3. Referencias humanas externas

Pedir 20-30 ejemplos reales de:

- autores de fantasia;
- bookstagram/booktok en espanol;
- lectores comentando libros;
- cuentas culturales con buen engagement.

No copiar texto. Extraer estructura.

### 4. Banco de hooks humanos

Pedir frases recogidas de lenguaje real de lectores:

- reseñas;
- comentarios;
- foros;
- X/Threads;
- TikTok.

Separar por emocion: humor, duelo post-libro, fantasia, villanos, secundarios, bloqueo lector, proceso de autor.
