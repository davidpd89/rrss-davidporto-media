# SKILL: EXTRAER PATRON HUMANO

Usar cuando se tenga una publicacion propia ganadora, referencia externa o post rival.

Objetivo: copiar estructura, no contenido.

---

## FASE 1 - DESPIECE

Registrar:

```yaml
referencia:
  fuente:
  red:
  formato:
  tema:
  primera_frase:
  estructura:
  ritmo:
  visual:
  cta:
  senal_metricas:
```

---

## FASE 2 - PATRON

Extraer patron en abstracto:

```text
[situacion concreta] -> [contradiccion] -> [remate/pregunta]
```

Ejemplo:

```text
lector dice que va a hacer algo responsable -> libro/interrupcion lo contradice -> pregunta de complicidad
```

---

## FASE 3 - VARIANTES DAVID PORTO

Crear 3 variantes propias:

1. Variante lectora cotidiana.
2. Variante fantasia/libro.
3. Variante autor/proceso.

Cada variante debe cambiar:

- sujeto;
- situacion;
- remate;
- visual.

Si solo cambia vocabulario, es calco y no sirve.
