# SKILL: METRICAS Y APRENDIZAJE

Usar para revisar publicaciones ya publicadas y convertir datos en decisiones.

---

## FASE 1 - RECOGER DATOS

Fuentes:

- Metricool via `tools/metricool_client.py`.
- `06_Seguimiento/seguimiento_activo.md`.
- `06_Seguimiento/tracking_formatos_tecnicas_temas.md`.

Separar por red y formato. No comparar un reel con una quote card como si fueran equivalentes.

---

## FASE 2 - CLASIFICAR

Para cada pieza:

```yaml
pieza:
  id:
  red:
  formato:
  hook:
  tema:
  tecnica:
  metricas:
  diagnostico:
  repetir:
  evitar:
```

---

## FASE 3 - DECISION

Cada lectura debe producir al menos una regla:

- repetir estructura;
- repetir tema con formato distinto;
- pausar tema;
- cambiar hora;
- cambiar duracion;
- cambiar red;
- matar formato.

No cerrar con "ha ido bien/mal" sin accion.
