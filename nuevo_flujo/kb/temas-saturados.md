# TEMAS SATURADOS

Actualizar con postmortem semanal y tracking.

## Avisos actuales

| Tema | Estado | Regla |
|---|---|---|
| Libros pendientes/a medias/sin leer | Saturado historico | Usar solo con giro visual o pregunta nueva. |
| Magia con coste/worldbuilding | Saturado historico | No usar como default de fantasia. |
| Puertas/portales | Riesgo de saturacion | Usar solo si el mecanismo de participacion cambia. |
| Metaforas de peso/distancia/huidas | Debil en reels | Evitar como gancho inicial. |
